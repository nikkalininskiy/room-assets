# DECISIONS.md — Принятые решения

## Стек

| Компонент | Выбор | Причина |
|-----------|-------|---------|
| Фреймворк | React 19 + TypeScript | Типизация, компоненты |
| Сборка | Vite | Быстрый dev-сервер, HMR |
| UI | MUI | Готовые компоненты |
| Хранилище | IndexedDB | Асинхронность, транзакции |
| Моки | MSW | Реалистичное тестирование |
| HTTP | Axios | Интерсепторы, простота |

## IndexedDB vs localStorage

**Выбран IndexedDB:**
- Асинхронный
- Транзакции
- Индексы
- Нет лимита 5 МБ

## Время

- Хранение: **UTC** (ISO 8601)
- Отображение: **локальное**

## Авторизация

- React Context API
- localStorage для сессии
